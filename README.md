# Учебный менеджер

Учебный проект по курсу «Практический курс веб-разработки: React, TypeScript, Node и Supabase».

**Автор:** ЛЫсогор М.С., группа ФТ24ДР62ПИ1

## Основной сценарий

Учебный менеджер помогает студенту вести учебные задания. Пользователь добавляет задание, выбирает курс и дедлайн, меняет статус и находит просроченные задания.

## Стек

React, TypeScript, Vite, npm, Git

## Версия Node

22.20.0 (также указана в файле `.node-version`)

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

## Проверка сборки

Останови dev через Ctrl+C. В папке `frontend`:

```bash
npm run build
npm run preview
```

## Что работает сейчас

Локальный CRUD заданий (создание, просмотр, редактирование, удаление с подтверждением), фильтр по статусу. Курс задания выбирается из справочника, который загружается по HTTP из `frontend/public/demo/courses.json` (запрос `GET /demo/courses.json`). Ответ проверяется: статус, структура и уникальность `id`. Форма показывает ожидание, ошибку и пустой справочник, есть кнопка «Повторить». Пока справочник недоступен или курс не выбран, сохранить задание нельзя.

**Основные записи хранятся только в памяти:** после обновления страницы возвращаются демонстрационные задания.

## Адреса страниц

| Адрес | Страница |
|---|---|
| `/` | переход на `/assignments` |
| `/assignments` | список заданий с фильтром по статусу |
| `/assignments/new` | создание задания |
| `/assignments/:id` | подробности, кнопки «Изменить» и «Удалить» |
| `/assignments/:id/edit` | редактирование задания |
| любой другой | «Страница не найдена» |
