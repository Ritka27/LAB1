# Учебный менеджер

Учебный проект по курсу «Практический курс веб-разработки: React, TypeScript, Node и Supabase».

**Автор:** ЛЫсогор М.С., группа ФТ24ДР62ПИ1

## Основной сценарий

Учебный менеджер помогает студенту вести учебные задания. Пользователь добавляет задание, выбирает курс и дедлайн, меняет статус и находит просроченные задания.

## Стек

React, TypeScript, Vite, npm, Git

## Версия Node

22.20.0 (также указана в файле `.node-version`)

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

## Проверка сборки

Останови dev через Ctrl+C. В папке `frontend`:

```bash
npm run build
npm run preview
```

## Что работает сейчас

Список из пяти демонстрационных заданий, карточка задания по адресу, страница создания (заглушка), общий layout с навигацией, страницы для неизвестного адреса и отсутствующей записи. Данные хранятся в типизированном массиве.

## Адреса страниц

| Адрес | Страница |
|---|---|
| `/` | переход на `/assignments` |
| `/assignments` | список заданий |
| `/assignments/:id` | подробности задания (например, `/assignments/a1`) |
| `/assignments/new` | создание задания (заглушка, форма будет в ЛР 3) |
| любой другой | «Страница не найдена» |

Записи демонстрационные (вымышленные).
