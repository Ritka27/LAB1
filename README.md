# Учебный менеджер

Учебный проект по курсу «Практический курс веб-разработки: React, TypeScript, Node и Supabase».

**Автор:** ЛЫсогор М.С., группа ФТ24ДР62ПИ1

## Основной сценарий

Учебный менеджер помогает студенту вести учебные задания. Пользователь добавляет задание, выбирает курс и дедлайн, меняет статус и находит просроченные задания.

## Стек

React, TypeScript, Vite, npm, Git

## Версия Node

22.20.0 (также указана в файле `.node-version`)

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

## Проверка сборки

Останови dev через Ctrl+C. В папке `frontend`:

```bash
npm run build
npm run preview
```

## Что работает сейчас

Начальный экран с названием, описанием и заглушкой списка заданий. Проходят проверка типов и сборка.

## Текущие ограничения

Данные, формы, маршрутизация, Supabase, авторизация и Node API будут добавлены в следующих лабораторных.

## Использование ИИ

ИИ помогал разобраться со структурой проекта и с ошибками запуска. Самостоятельно проверено: запуск в браузере, ошибка типов, сборка, preview и запуск из чистой копии.
