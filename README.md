# Учебный менеджер

Учебный проект по курсу «Практический курс веб-разработки: React, TypeScript, Node и Supabase».

**Автор:** ЛЫсогор М.С., группа ФТ24ДР62ПИ1

## Основной сценарий

Учебный менеджер помогает студенту вести учебные задания. Пользователь добавляет задание, выбирает курс и дедлайн, меняет статус и находит просроченные задания.

## Стек

React, TypeScript, Vite, npm, Git, Supabase (PostgreSQL, клиент `@supabase/supabase-js`)

## Версия Node

22.20.0 (также указана в файле `.node-version`)

## Настройка Supabase

1. В SQL Editor проекта Supabase выполни целиком `supabase/migrations/202611062351_initial_schema.sql`, затем `supabase/seed.sql` (подробно — в [docs/progress.md](docs/progress.md)).
2. Создай `frontend/.env.local` по образцу `frontend/.env.example` и впиши значения из Dashboard (Connect или Settings → API Keys):

| Переменная | Что это |
|---|---|
| `VITE_SUPABASE_URL` | адрес проекта Supabase |
| `VITE_SUPABASE_PUBLISHABLE_KEY` | publishable key (публичный ключ приложения) |

Во frontend допустим только publishable key. Secret key, service_role и пароль базы не используются. `.env.local` не попадает в Git, `.env.example` — попадает. После изменения env-файла перезапусти Vite. Если переменных нет, приложение сообщает «Не настроены переменные Supabase в .env.local».

## Что работает сейчас

Локальный CRUD заданий (создание, просмотр, редактирование, удаление с подтверждением), фильтр по статусу. Курс задания выбирается из справочника, который загружается **из Supabase** (таблица `public.courses`, сервис `frontend/src/services/courses.ts`). Ответ проверяется функцией `parseCourses`. Форма показывает ожидание, ошибку и пустой справочник; при ошибке есть кнопка «Повторить», после загрузки — «Обновить справочник». Обе не стирают черновик формы. Пока справочник недоступен или курс не выбран, сохранить задание нельзя. Файл `public/demo/courses.json` удалён: запасного источника нет, ошибка Supabase видна в форме.

**Основные записи пока хранятся только в памяти.** Таблица `public.assignments` уже создана в базе, но закрыта от браузера до ЛР 6. После обновления страницы возвращаются демонстрационные задания из `frontend/src/data/assignments.ts`.

## Схема данных (кратко)

| Таблица | Назначение | Ключ | Связь | Доступ |
|---|---|---|---|---|
| `public.courses` | справочник курсов | `id` (text) | — | публичный, только чтение |
| `public.assignments` | задания пользователя | `id` (uuid) | `course_id` → `courses.id`, `owner_id` → `auth.users.id` | личная таблица, пока закрыта |

Подробнее — в [docs/progress.md](docs/progress.md).

## Адреса страниц

| Адрес | Страница |
|---|---|
| `/` | переход на `/assignments` |
| `/assignments` | список заданий с фильтром по статусу |
| `/assignments/new` | создание задания |
| `/assignments/:id` | подробности, кнопки «Изменить» и «Удалить» |
| `/assignments/:id/edit` | редактирование задания |
| любой другой | «Страница не найдена» |
