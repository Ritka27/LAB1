# Прогресс

## ЛР 1: старт проекта на React и TypeScript

Создан проект React + TypeScript + Vite в папке `frontend`, заменён стартовый экран на «Учебный менеджер», настроен Git и отправлен репозиторий на GitHub.

### Проверка

1. `cd frontend`, `npm ci`, `npm run dev`: открывается экран с названием и заглушкой списка.
2. Временно `appTitle = 123`, `npm run build`: TypeScript выдаёт ошибку.
3. Исправление на строку, `npm run build`: сборка проходит.
4. `npm run preview`: готовая сборка открывается в браузере.
5. Клонирование в `course-app-check`, `npm ci`, `npm run build`: проект запускается из чистой копии.
## ЛР 2: страницы приложения и навигация

Добавлен React Router (`react-router`), типы и демонстрационные данные (5 заданий), компонент `AssignmentCard`, страницы списка, подробностей, создания (заглушка) и неизвестного адреса, общий `AppLayout` с `Outlet`, стили.

### Проверка

1. `/` перенаправляет на `/assignments`, показаны 5 карточек.
2. Две разные карточки открываются с разным содержимым.
3. Адрес карточки в новой вкладке и обновление страницы (F5) работают.
4. `/assignments/new` показывает заглушку и общую навигацию.
5. `/unknown` показывает «Страница не найдена».
6. `/assignments/missing` показывает «Задание не найдено».
7. Пустой массив показывает «Заданий пока нет.»
8. `npm run build` и `npm run preview`: прямое открытие карточки работает.

## ЛР 3: формы и локальное состояние

Список заданий перенесён в состояние `App` (`useState`), добавлены функции создания, изменения и удаления без мутаций массива. Сделана общая форма `AssignmentForm` с отдельным черновиком, проверкой полей и предметным правилом (описание не короче 10 символов), страница редактирования, удаление с подтверждением, фильтр по статусу со сбросом, пояснение о временном хранении.

### Проверка

1. Создание записи: открывается её карточка, список содержит новую запись.
2. Редактирование: изменения видны в карточке и списке, id сохраняется.
3. «Отмена» не меняет сохранённую запись.
4. Пустое название, пробелы, пустой курс или дедлайн, короткое описание: ошибка видна, поля не сбрасываются.
5. Фильтр по статусу, сброс, сообщение об отсутствии совпадений.
6. Удаление: отмена оставляет запись, подтверждение удаляет; адрес удалённой записи показывает «Задание не найдено».
7. Пустой список и создание записи из него.
8. После F5 возвращаются демонстрационные записи.
9. `npm run build` и `npm run preview` проходят.
## ЛР 4: загрузка справочника по HTTP

Справочник курсов лежит в `frontend/public/demo/courses.json`. Добавлены тип `Course` (`src/types/course.ts`), сервис с проверкой ответа (`src/services/courses.ts`), хук загрузки (`src/hooks/useCourses.ts`). В форме `AssignmentForm` курс выбирается из загруженных данных, в задании хранится `id` курса, название берётся из справочника.

### Проверка

1. Открыть `/assignments/new`: в Network виден `GET courses.json` со статусом 200, в форме выбор из пяти курсов.
2. Медленная сеть: видно «Загружаем курсы…», кнопка «Сохранить» недоступна, остальные поля доступны.
3. Offline: ошибка и кнопка «Повторить». Ввести название, вернуть Online, нажать «Повторить»: курсы загрузились, название осталось.
4. Неверный путь в `coursesUrl`: ошибка загрузки (путь возвращён).
5. `courses.json` с `[]`: сообщение «Курсов пока нет», сохранение недоступно.
6. Неверная структура (объект вместо массива, `id` числом, нет `name`, повтор `id`): ошибка структуры.
7. Уход со страницы во время загрузки: устаревший ответ не влияет на другие страницы.
8. После возврата данных: создание, редактирование, отмена, удаление и фильтр работают.
9. `npm run build` и `npm run preview`: справочник доступен в готовой сборке.
